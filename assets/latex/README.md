# LaTeX 模板

两个赛事的论文模板，均已实际编译验证：

| 模板 | 赛事 | 编译方式 | 验证结果 |
|---|---|---|---|
| `cumcm/main.tex` | 全国大学生数学建模竞赛 | `xelatex main.tex`（跑两遍） | 编译通过，13 页 |
| `mcm/main.tex` | 美赛 MCM/ICM | `pdflatex main.tex`（跑两遍） | 编译通过，9 页 |

国赛模板必须用 **XeLaTeX**（要调用系统中文字体）；美赛模板用 pdfLaTeX 即可。跑两遍是为了解析 `\ref` / `\eqref` 的交叉引用。

```bash
# 国赛
cd assets/latex/cumcm
xelatex -interaction=nonstopmode main.tex && xelatex -interaction=nonstopmode main.tex

# 美赛
cd assets/latex/mcm
pdflatex -interaction=nonstopmode main.tex && pdflatex -interaction=nonstopmode main.tex
```

## 队伍信息怎么替换

- **国赛模板**：第 1 页承诺书里的 6 处 `\teamfield{说明文字}{占位内容}`，只改**第二个参数**。若某项不需要（例如没有指导教师），删掉整行。
- **美赛模板**：页眉里的 `Team # 0000000` 改成你的控制号。除此之外**任何地方都不要出现**姓名、指导教师、学校。

身份信息只允许出现在国赛的承诺书页与编号专用页上。摘要页、正文、附录里一律不得出现——包括代码注释和文件路径。

## 模板里已经配好的格式

这些是自己从零写导言区最容易配错的地方，模板已经处理：

- 页边距 ≥ 2.5cm（国赛官方下限）
- 国赛页码：从摘要页起算为 1，页脚中部；承诺书页与编号专用页不编号
- 国赛**不含目录**（官方明令"不要目录"）
- 美赛页眉：`Team # 编号, Page X of 25`
- 三线表（`booktabs`）、公式居中自动编号、图题在下表题在上
- 中文字体、1.5 倍行距、首行缩进两字
- 代码附录的 `listings` 配置

## 两个赛事的关键差异

混用会直接出问题，因为多处要求**方向相反**：

| 项目 | 国赛 | 美赛 |
|---|---|---|
| 语言 | 中文 | 英文 |
| 页数上限 | 正文 ≤ 30 页 | 全文件 ≤ 25 页 |
| 页数范围 | 仅正文，**附录不限** | **含附录与代码** |
| 目录 | **不要** | **鼓励**，计入 25 页 |
| 页码位置 | 页脚中部 | 每页顶部 |
| 首页 | 承诺书（电子版从摘要页起） | Summary Sheet |
| AI 声明 | **参考文献之前** | **正文之后** |

完整条款与出处见 `references/cumcm.md` 与 `references/mcm.md`。

## 一条必须记住的声明

模板注释里给出的页数、摘要字数等口径，依据的是：

- 国赛：《全国大学生数学建模竞赛论文格式规范（**2026 年修订稿**）》与《人工智能工具使用规定（**2026 年试行**）》
- 美赛：COMAP 现行 *MCM/ICM Contest Rules, Registration and Instructions*

**这些规范每年都可能修订。**国赛正文上限就从 2025 年的 20 页改成了 2026 年的 30 页。正式参赛前必须以当年官方发布的通知与规范原文为准。
